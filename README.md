# Golden Crumb Bakery Website

A responsive single-page bakery website.

## Files
- `index.html` — page structure/content
- `styles.css` — all styling and responsive design
- `script.js` — mobile navigation and current year

## Run it
Just double-click `index.html` to open it in a browser.

For deployment, upload all three files to any static web host such as GitHub Pages, Cloudflare Pages, Netlify, Vercel, or a standard web server.

## Customising
Search the files for:
- `Golden Crumb` to rename the bakery
- `123 Baker Street` to update the address
- `(02) 1234 5678` to update the phone number
- `hello@goldencrumb.com.au` to update the email
- Product names/prices in the `#menu` section

The large emoji graphics are intentionally placeholders so the site works without downloading image assets.
Replace them with your own bakery photography whenever you're ready.
